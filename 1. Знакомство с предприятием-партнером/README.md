## О компании
* **ООО «Синаптик»** — кировская аккредитованная ИТ-компания (на рынке с 2012 года), которая занимается разработкой программного обеспечения и автоматизацией бизнес-процессов.
* **Основные направления:** разработка собственной модульной ERP-системы для управления производством, заказная веб- и мобильная разработка, ИТ-консалтинг.
* **Технологический стек:** TypeScript / JavaScript, Dart, реляционные БД, инструменты бизнес-аналитики.

## Итоги знакомства
* **Мое впечатление:** в рамках производственной практики ознакомился с деятельностью и проектами компании. Организация совмещает заказную разработку с развитием собственной платформы,  
поэтому имеет большой объем задач по работе с бизнес-данными.
* **План работы:** в ходе практики предстоит выполнить три кейса от партнера — поиск нетипичного поведения заявок на закупку, восстановление процесса по журналу событий и генерация продуктовых гипотез.
